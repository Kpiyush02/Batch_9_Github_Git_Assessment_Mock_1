# Task: Absolute Element — Top Right Corner

## Objective

Create a **box** that contains an element positioned absolutely at the **top-right corner** of the box.

## Requirements

* Create a parent `div` representing the box.
* Give the box a fixed width and height.
* The box should have `position: relative`.
* Create a child element inside the box.
* The child element should have `position: absolute`.
* Position the child element at the **top-right corner** using:

  * `top`
  * `right`

## Expected Structure

```html
<div class="box">
    <div class="element"></div>
</div>
```

## Expected Result

The child element should appear at the **top-right corner inside the box**.

### Concepts to Practice

* `position: relative`
* `position: absolute`
* `top`
* `right`
* Parent-child positioning relationship
